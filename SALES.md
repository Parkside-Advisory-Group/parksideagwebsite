# Sales

## Primary CTA

Get the Free AI Workflow Savings Snapshot.

## Funnel

1. Free AI Workflow Savings Snapshot
   - lightweight diagnostic from intake
   - identifies likely leaks, practical AI/workflow opportunities, readiness gaps, and the first system worth considering
   - no fixed pricing, no exact savings promise, no guaranteed feasibility
2. Paid AI Operations Blueprint
   - deeper workflow map and implementation plan
   - used when the Snapshot shows a real opportunity worth scoping
3. Workflow Automation Sprint / AI Agent Build
   - scoped implementation of the first useful system
4. AI Operations Retainer
   - ongoing tuning, expansion, and operational support

## Qualification Signals

Strong-fit prospects usually have:

- a recurring workflow pain
- clear business impact
- manual follow-up or visibility gaps
- existing tools that can be integrated or used as source systems
- a near-term desire to improve operations
- permission to follow up

## Lead Tiers

- 80-100: high priority; prepare Snapshot and recommend Blueprint conversation
- 60-79: good fit; prepare Snapshot and ask clarifying question if needed
- 40-59: nurture; send lighter Snapshot-style guidance and request more context
- below 40: not ready; educational follow-up without pressure

## Recommended Follow-Up

High priority and good fit leads should receive a useful Snapshot and then be invited to an AI Operations Blueprint discussion if the opportunity is real. Nurture leads should receive a practical request for more context. Not-ready leads should receive a light educational follow-up without pressure.

Do not discuss final pricing before discovery.

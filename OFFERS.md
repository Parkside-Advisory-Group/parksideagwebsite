# Offers

Pricing should stay behind intake and discovery because scope depends on workflow complexity, tools, data readiness, and implementation needs.

## 1. Free AI Workflow Savings Snapshot

A lightweight report generated from intake that identifies likely workflow leaks, practical AI/automation opportunities, readiness gaps, and the first system worth considering.

Primary public CTA: Get the Free Snapshot.

Purpose:

- collect real prospect workflow data
- demonstrate practical AI/workflow thinking
- qualify the lead
- create a natural path into the paid Blueprint

The Snapshot should not become unpaid consulting. It is a useful diagnostic, not a full implementation plan.

## 2. AI Operations Blueprint

A paid working session and roadmap that maps one recurring workflow in detail, identifies practical automation opportunities, and produces an implementation sequence.

Primary next step after a strong Snapshot: Start the AI Operations Blueprint.

## 3. Workflow Automation Sprint

A scoped implementation sprint for one recurring workflow such as intake, follow-up, reporting, handoffs, or routing.

## 4. AI Agent Build

A practical AI assistant or agent that supports qualification, summaries, drafting, triage, or guided internal processes.

## 5. AI Operations Retainer

Ongoing support to tune systems, extend automations, improve reporting visibility, and keep AI-supported workflows aligned with operations.
